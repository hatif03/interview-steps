# Archived Reference

This folder is the original **Prepwise** mock interview tutorial project (Vapi + Gemini + Firebase).

Its features have been integrated into the main app:
- Mock interview UI → `frontend/src/app/candidate/`
- Voice agent → `frontend/src/components/VoiceInterviewAgent.tsx` (Web Speech API, no Vapi)
- Feedback generation → `backend/app/services/mock_interview_service.py`
- Firebase patterns → `frontend/src/lib/firebase.ts`, `backend/app/firestore_repo.py`

This folder is kept for reference only and is not part of the active deployment.
